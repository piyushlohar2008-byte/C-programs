- Conditional Statements
- Loops

- Classes & Objects
- Constructors
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
- Exception Handling
- File Handling
- Collections
- Multithreading
- Practice Programs
- Projects

## 🎯 Purpose

This repository is created to:
- Practice Java programming.
- Improve problem-solving skills.
- Help beginners understand Java concepts.
- Store Java programs in one place.

## 🛠️ Technologies
